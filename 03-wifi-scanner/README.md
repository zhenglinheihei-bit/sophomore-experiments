# 📶 实验三 · WiFi 信号扫描仪

**不需要任何外部硬件、也不需要 WiFi 账号密码**：ESP32 自己开一个热点，手机连上去打开 `192.168.4.1`，就能看到周围所有 WiFi 的名称、信号强度条、信道和加密情况，按信号强弱排序，每 10 秒自动重扫。相当于一个简易版「WiFi 信号检测器」。

## 实验目的

- 掌握 ESP32 的 SoftAP 热点模式（`WiFi.softAP`）
- 学会异步 WiFi 扫描（`scanNetworks(true)` + `scanComplete`）与 RSSI 含义
- 练习把结构化数据整理成 JSON 并用网页动态渲染
- 理解「后台任务不阻塞 Web 服务」的程序结构

## 器材

| 器件 | 数量 |
| --- | --- |
| ESP32 开发板 | 1 |
| 手机 / 电脑 | 1 |

## 使用方法

1. 烧录后打开串口监视器（115200），可看到扫描结果同步打印（可直接截图进实验报告）
2. 手机 WiFi 列表里连接热点 **ESP32-Scanner**（无密码）
3. 浏览器打开 <http://192.168.4.1>
4. 页面每 8 秒自动刷新，也可点「立即扫描」；拿着手机 + ESP32 在屋里走一圈，观察不同位置的信号强度变化

## API

- `GET /api/networks` — 当前扫描结果 JSON：`[{"ssid":"...","rssi":-52,"channel":6,"secure":true}, ...]`
- `GET /api/scan` — 触发一次重扫

## 代码要点

- 扫描用**异步模式**，扫描期间 Web 服务不卡顿；结果处理完调用 `scanDelete()` 释放内存
- 信号强度换算：RSSI一般在 -30（极好）到 -90（极差）之间，页面按 `2×(RSSI+100)` 折算成百分比色条
- SSID 做了 JSON 转义与 HTML 转义，遇到特殊字符的网络名也不会出错

## 思考题

1. RSSI 是负数，为什么 -50 dBm 比 -80 dBm 信号更好？
2. 扫描时 ESP32 会在不同信道之间跳转，这对它自己的热点有什么影响？为什么用异步扫描而不是同步的 `scanNetworks()`？
3. 2.4GHz 只有信道 1~14 且相互重叠，扫出的结果里信道分布有什么规律？哪个信道最拥挤？
