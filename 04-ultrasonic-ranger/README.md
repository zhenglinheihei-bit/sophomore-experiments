# 📏 实验四 · 超声波测距仪

HC-SR04 超声波模块 + ESP32：手机直连 ESP32 热点，打开网页实时看到前方障碍物距离（cm）；距离小于 20cm 时板载 LED 快闪报警，网页同时变红提示——一个「倒车雷达」。采用滑动平均滤波，读数稳定不跳变。

## 实验目的

- 理解超声波测距原理（Trig 触发 → Echo 回波脉宽 → 距离）
- 掌握 `pulseIn()` 精确测量脉宽（微秒级）
- 学会用**滑动平均滤波**抑制单次测量毛刺
- 练习阈值判断 + 多种输出（LED / 网页 / 串口）联动

## 器材与接线

| 器件 | 数量 |
| --- | --- |
| ESP32 开发板 | 1 |
| HC-SR04 超声波模块 | 1 |
| 杜邦线 4 根 | — |

| HC-SR04 引脚 | 接到 ESP32 |
| --- | --- |
| VCC | 5V (VIN) |
| TRIG | GPIO5 |
| ECHO | GPIO18 |
| GND | GND |

> ⚠️ **注意**：HC-SR04 用 5V 供电时，ECHO 脚输出也是 5V，而 ESP32 引脚不耐 5V！
> 请在 ECHO 与 GPIO18 之间加分压电阻（1kΩ 上、2kΩ 下）；
> 或者直接给模块供 3.3V（大部分模块短距离内也能工作，最稳妥还是分压）。

## 使用方法

1. 按接线表接好 HC-SR04，烧录固件
2. 手机连接热点 **ESP32-Ranger**（无密码），浏览器打开 <http://192.168.4.1>
3. 手掌在模块前移动，观察距离变化与颜色：
   - 绿色（≥60cm）安全 · 黄色（20~60cm）偏近 · 红色（<20cm）报警 + LED 快闪
4. 串口（115200）每秒打印一次距离，方便记录数据画表格

## 代码要点

- 测距公式：`距离 = 回波脉宽(µs) × 0.0343 / 2`（声速 343m/s，来回双程除 2）
- `pulseIn` 设 30ms 超时，超量程/未接传感器时返回 0，固件将其过滤
- 最近 5 次有效测量做滑动平均；无效样例不进窗口，避免污染平均值

## 思考题

1. 为什么要除以 2？如果测的是水深（传感器朝下），公式还适用吗？
2. 声速受温度影响（约 0.6m/s/℃）。把实验一的 DHT22 接进来做温度补偿，公式应该怎么改？
3. 滑动平均会让读数「变慢」。窗口大小取 5 是权衡了什么？想又稳又快有什么办法？（提示：中值滤波、丢弃离群值）
