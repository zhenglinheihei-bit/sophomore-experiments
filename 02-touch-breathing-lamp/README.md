# 💡 实验二 · 触摸呼吸灯

**不需要任何外部硬件**：板载 LED 由 PWM 驱动呼吸，触摸 ESP32 的 T0 引脚（GPIO4）即可切换 4 种模式——慢呼吸 → 快呼吸 → 心跳 → 熄灭。开机时自动校准触摸灵敏度，不同开发板都能可靠识别。

## 实验目的

- 掌握 ESP32 的 LEDC PWM 输出（`ledcSetup` / `ledcWrite`）
- 学会使用电容触摸传感器 `touchRead` 并做自动校准
- 理解「非阻塞」程序结构：用 `millis()` 计时代替 `delay()` 大延时
- 了解伽马校正对视觉亮度的作用

## 器材

| 器件 | 数量 | 说明 |
| --- | --- | --- |
| ESP32 开发板 | 1 | 板载 LED（GPIO2）即可，无需外接灯 |
| 杜邦线 | 可选 | 插在 GPIO4 上当触摸电极，效果更好 |

## 现象

1. 烧录后打开串口（115200），**前 2 秒不要碰 GPIO4**（自动校准）
2. 串口会打印校准出的基准值和阈值
3. LED 缓慢呼吸；用手指触摸 GPIO4（或其上的杜邦线金属头）：
   - 第 1 次触摸 → 快速呼吸
   - 第 2 次触摸 → 心跳双脉冲节奏
   - 第 3 次触摸 → 熄灭
   - 第 4 次触摸 → 回到慢呼吸
4. 每次切换模式，串口都会打印当前模式名

## 代码要点

- PWM 频率 5kHz、分辨率 8 位（占空比 0~255），呼吸曲线用余弦函数生成、再做 1.6 次伽马校正
- 触摸检测用「开机基准 + 阈值」自动适应，无需手调魔法数字
- 模式切换采用下降沿检测 + 300ms 消抖，按住不放只切换一次

## 思考题

1. 直接线性增加占空比的呼吸灯，为什么看起来「前半程快、后半程慢」？
2. `delay(2000)` 等待校准在这里可以接受；但如果要加一个「校准期间按住其他触摸键取消」的功能，该怎么改？
3. 触摸值受电源、湿度、接线影响波动，除了开机校准，还可以怎样让判定更稳定？（提示：中值滤波 / 迟滞比较）
